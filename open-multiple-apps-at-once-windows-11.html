How to open multiple apps at once in Windows 11

You can start a group of apps at sign-in, from a script, or with a saved workspace. The simplest choice depends on when the apps should open and whether their window positions matter.

Short answerUse Windows Startup for apps needed at every sign-in, a batch or PowerShell script for a fixed launch list, PowerToys Workspaces for apps plus positions, or suko to switch complete task contexts by hotkey, schedule or environment.

Updated September 19, 2026 · 6 minute read

Choose how the apps should start

Opening several apps is easy. The important question is whether they should open every time Windows starts or only when you begin a specific task. Loading everything at sign-in can slow startup and leave unrelated apps running all day.

Option 1: Windows Startup

Use Startup for software you genuinely need after every sign-in, such as a password manager or accessibility tool. Windows lets you manage supported entries under Settings → Apps → Startup. Microsoft’s Startup applications guide explains the available methods.

A project editor, research browser profile and music player usually do not belong there if you only need them for one kind of work.

Option 2: a batch or PowerShell script

A script is the smallest built-in solution for a fixed list. A PowerShell file can contain one line per program:

Start-Process "notepad.exe"
Start-Process "https://calendar.google.com"

Create a shortcut to the script when you want one-click launching. This works well for technical users, but you must maintain application paths and add your own logic if programs need delays, arguments or specific browser profiles.

Option 3: PowerToys Workspaces

Microsoft PowerToys Workspaces captures open applications and their screen positions. Launching the workspace reopens those applications into the recorded layout. Choose this when launching and positioning are the main requirements.

Option 4: a suko mode

A suko mode combines desktop apps, URLs, browser profiles and terminal commands. It can close managed apps from the previous mode before opening the next group, restore a multi-monitor layout, and change volume, brightness or Do Not Disturb. The same mode can start through a shortcut, schedule, Wi-Fi network, power state or application launch.

Create a one-shortcut app group with suko

  1. Create a mode for the activity, not for the individual apps—for example, Client Work or Study.
  2. Add every launch target: desktop programs, web pages, a browser profile and any terminal command.
  3. Arrange and capture the windows if the group should return to a consistent layout.
  4. Add system preferences such as volume, brightness and Do Not Disturb.
  5. Bind a shortcut or trigger, run it, and remove anything that does not help the task.

Keep the group reliable

  • Prefer stable executable paths rather than temporary shortcuts.
  • Do not launch two copies of an app that already manages its own single instance.
  • Give slow applications enough time to create their main window before restoring the layout.
  • Use a dedicated browser profile when the workspace needs a separate account or set of bookmarks.
  • Keep Startup lean; launch task-specific tools only when the task starts.

Questions

Can Windows 11 open multiple apps with one shortcut?

Yes. A batch or PowerShell script can start several applications. PowerToys Workspaces and suko can also restore window positions.

Should I put every work app in Windows Startup?

Usually no. Startup suits apps needed after every sign-in. Launching task-specific groups on demand keeps startup and the desktop cleaner.
