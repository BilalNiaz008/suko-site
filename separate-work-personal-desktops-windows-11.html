How to separate work and personal desktops in Windows 11

One PC can serve both sides of your day without leaving every work window next to your personal apps. Start with Windows' built-in desktops, then separate browser accounts and decide whether the app setup should change too.

Short answerPress Win + Tab, select New desktop, and name your desktops Work and Personal. Move the right windows onto each. Use separate browser profiles for work and personal accounts. If changing contexts should also close selected old apps, launch the next group, restore its window layout and apply settings, create suko modes for those tasks.

Updated October 7, 2026 · 5 minute read

Create Work and Personal desktops

  1. Press Win + Tab to open Task View, then select New desktop.
  2. Rename one desktop Work and the other Personal. Open the apps you need on each, or move an existing window to the intended desktop from Task View.
  3. Use Win + Ctrl + ← or → to switch between desktops without opening Task View.
  4. Optionally choose a different background for each desktop so you can tell at a glance which context is active.

Microsoft's multiple-desktops guide describes Work and Personal separation as a common use case. It also documents desktop names, different backgrounds and the Settings → System → Multitasking → Desktops controls. There you can choose whether the taskbar shows windows from only the current desktop or from all desktops.

A virtual desktop is a visual workspace inside the same Windows session. It does not create another Windows account, a separate set of files, or a privacy barrier. Notifications and background apps can still reach you. If another person uses the computer or you need account-level separation, create a separate Windows user account instead.

Keep work and personal browser activity apart

Even with two desktops, opening the same browser profile on both can mix accounts, bookmarks and tabs. Create a Work profile and a Personal profile in your browser, then open the appropriate profile in each context. In Microsoft Edge, select the profile icon and add another profile; Microsoft's profile guide covers creating and switching profiles.

Start with a simple rule: work email, calendars and project sites belong in the Work profile; personal accounts belong in Personal. This reduces accidental sign-ins to the wrong account. A browser profile is still inside your Windows account, so it does not replace a separate Windows user when you need stronger separation.

Make the app setup repeatable

Windows desktops help you organize windows that are already open. They do not build a fresh task setup for you. If every work session starts with an editor, a project folder, chat, a work browser profile and the same two-monitor arrangement, you still have to launch and place those apps unless you save that routine.

A suko mode stores the apps, URLs, browser profile, window layout and Windows settings for an activity. A Work mode can open the work set, position the windows, lower the volume and turn on Do Not Disturb. A Personal mode can open a different set and close selected managed Work apps when you switch. The suko mode walkthrough shows the app and close-on-switch controls.

  1. Create a Work mode with only the apps, folders and sites you repeatedly use for work.
  2. Arrange and save the Work window layout, then choose any volume, brightness or Do Not Disturb settings that belong to it.
  3. Create a Personal mode with its own app list and layout. Select which managed Work apps should close when you leave Work; keep persistent tools outside that list.
  4. Give each mode a distinct hotkey and test the transition with your real apps. Check unsaved documents before allowing an app to close.

Windows virtual desktops and suko modes solve different parts of this setup. You can use both: virtual desktops organize open windows, and modes prepare or retire the apps for a task. Do not assume a suko mode automatically selects a particular Windows virtual desktop; test how you want to combine them. Our virtual desktop comparison explains that boundary in more detail.

Common questions

Do Windows 11 virtual desktops separate my work and personal accounts?

No. They organize windows inside one Windows session. Use browser profiles for separate web accounts, or separate Windows user accounts when you need account-level separation.

Will closing a virtual desktop close its apps?

Do not use desktop removal as an app-cleanup method. Close the apps you intend to finish, or switch a managed app group with a suko mode.

Can I use suko with Windows virtual desktops?

Yes. Use Windows desktops to organize visible windows and suko modes for repeatable app and setting changes. Test the workflow rather than assuming a mode selects a specific Windows desktop.
