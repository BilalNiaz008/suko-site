How to schedule apps to open at a specific time in Windows 11

Want a program to open at 9:00 each morning instead of every time you sign in? Windows can schedule one app. A workspace mode can prepare the whole set of apps and settings for that part of your day.

Short answerOpen Task Scheduler, create a basic task with a daily or weekly trigger, and choose Start a program as its action. Select the app's executable and test the task. If you want several apps, web pages, a window layout and settings to change together, schedule a suko mode instead.

Updated October 2, 2026 · 5 minute read

Choose the right kind of automatic launch

There are three different triggers people often call “automatic startup.” They solve different problems. Startup apps run when you sign in. Task Scheduler can run a program at a chosen clock time. A scheduled workspace starts the group of apps and settings that belong to an activity, such as Work or Study.

If you only need a password manager after every sign-in, use Windows Startup settings. To bring back supported apps from before a reboot, see how to reopen apps after restart. If you want Notepad or another single app at a specific time, Task Scheduler is already built into Windows. If you repeatedly prepare several apps, tabs and monitors together, use a workspace schedule.

Schedule one app with Task Scheduler

  1. Open Start, search for Task Scheduler, and open it.
  2. Select Create Basic Task in the Actions pane. Give the task a clear name, such as “Open notes at 9 AM.”
  3. Choose Daily or Weekly and set the time and days. For a workday routine, choose Weekly and select Monday through Friday.
  4. Choose Start a program. Select Browse and pick the application executable, for example notepad.exe. Use the actual executable path for another desktop app.
  5. Review the summary, select Finish, then find the task in Task Scheduler Library. Right-click it and select Run to check that the correct program opens.

Microsoft describes Task Scheduler as a tool that starts applications when a trigger is met, including a specific time or a daily or weekly schedule. The task runs on your Windows computer; it does not turn the computer on from a full shutdown. For a visible desktop app, test while you are signed in. If the task runs in the background without a window, open its properties and check the Run only when user is logged on setting on the General tab.

For a command-line example, Windows also includes schtasks /create. The graphical Task Scheduler is easier when you only need one or two app schedules.

Schedule several apps for one task

You can make a separate scheduled task for each application. That works when each app has an independent schedule. For a single work routine, separate tasks quickly become hard to manage: one opens the editor, another opens chat, and a third opens a browser, but none knows where the windows belong or which apps from yesterday's task should close.

A suko mode groups those choices. For example, a weekday Work mode can include an editor, a project folder, a browser profile and a team chat, plus the positions of those windows on your monitors. It can also set your preferred volume and Do Not Disturb state. The suko mode walkthrough shows the scheduling and app controls in the desktop app.

  1. Create a mode for the activity and add only the apps, URLs, files and folders you need together.
  2. Arrange the windows, save the layout, and set any mode-specific Windows controls you want.
  3. Set the mode's schedule for the correct time and days. Review the time zone on the computer that will run it.
  4. Activate the mode manually once before relying on its schedule. Check slow apps, duplicate windows and any launch delay you need.

Keep an easy manual way to start the same mode, such as its hotkey, for mornings when the computer was off or asleep at the scheduled time. If the workday should also be quiet, see how to turn on Do Not Disturb automatically. If the schedule does not open the app

  • Check the trigger: confirm the date, time, selected days and the computer's clock. A daily task does not run at sign-in unless you also configure that trigger.
  • Run it manually: if the task fails when you select Run, check the executable path and any arguments before troubleshooting the time.
  • Check the session: a task configured to run without a signed-in user may start a process without showing its window on your desktop. Use the interactive logon option for a visible app.
  • Check sleep and power: an app cannot appear on a sleeping or powered-off desktop. In the task's Conditions and Settings tabs, review the power and missed-run behavior that matches your setup.
  • Check app-specific behavior: some apps reuse an existing window, while others open a second one. Test the real app before scheduling a whole set.

If your apps open but land on the wrong screen, follow the second-monitor guide to correct the display layout and save window positions.

Common questions

Can Windows 11 open an app at a specific time without extra software?

Yes. Task Scheduler can start a desktop program on a daily or weekly trigger. Create a basic task, choose Start a program, and test it from Task Scheduler Library.

Will Task Scheduler open my apps if the PC is shut down?

No. The computer must be running for a scheduled task to execute. If it is asleep, behavior depends on the task's power settings and whether the hardware can wake for the task.

How do I open multiple apps every weekday morning?

Create a scheduled task per app, or schedule one suko mode containing the apps, URLs, layout and settings you use together. Test the mode manually first.
