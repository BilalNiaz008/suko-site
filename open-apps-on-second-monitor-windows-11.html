How to open apps on a second monitor in Windows 11

Move a window to your other screen in seconds. When you need the same apps on the same monitors every day, save the entire arrangement so you can launch it again.

Short answerSet your displays to Extend, select the app window, then press Win + Shift + ← or → to move it between monitors. For a repeatable launch, capture the apps and their positions with PowerToys Workspaces or a suko mode. Windows' monitor-memory setting helps with reconnecting displays; it does not assign every newly opened app to monitor 2.

Updated October 1, 2026 · 5 minute read

First, make sure Windows sees two separate screens

Press Win + P and choose Extend. In Duplicate mode both monitors show the same desktop, so there is no separate space where an app can stay. Open Settings → System → Display, select Identify, then drag the numbered display rectangles until they match the physical left-to-right order on your desk. Select Apply.

Microsoft's multiple-monitor guide documents the Identify, Detect, arrangement and display-mode controls. If the second screen is missing, expand Multiple displays and select Detect; check the cable or dock connection before changing app settings.

Move one open app to the second monitor

  1. Click the app window so it is active.
  2. Press Win + Shift + → to move it to the monitor on the right, or Win + Shift + ← for the one on the left.
  3. Resize or snap it where you want. Repeat for any other open apps.

Those are the default shortcuts in Microsoft's Windows keyboard shortcut list. If the direction feels backward, correct the display order in Settings. You can also drag the window by its title bar across the screen edge.

This moves a window that is already open. It does not create a lasting per-app rule. Some apps remember where you closed them; others choose a new position on their next launch. Test by moving one app, closing it normally, and reopening it before assuming its placement is saved.

Make apps return to the right monitors

If the issue happens after unplugging a laptop or waking it from sleep, turn on Remember window locations based on monitor connection under Settings → System → Display → Multiple displays. Arrange the open windows, disconnect and reconnect the monitor, then see whether they return. This Windows setting is specifically about monitor reconnection, as Microsoft explains.

If you want to open a group of apps on chosen screens after a reboot, create a saved workspace. That gives you a repeatable launch instead of relying on each app to remember its own last position.

Use PowerToys Workspaces for a saved app layout

In PowerToys Workspaces, enable Workspaces, launch its editor, and select Create workspace. Open and arrange the apps across both monitors, select Capture, then name and save the workspace with a desktop shortcut. Launching that shortcut opens the recorded apps and moves their windows to the saved positions.

PowerToys can also move already-open windows when Move existing windows is enabled. Its documentation notes that applications differ: one may reuse an existing window while another opens a new instance. Test the actual apps you use before depending on the layout.

Use a suko mode when you switch tasks

A suko mode can store the applications, URLs, window positions and Windows settings for one activity. For example, a Work mode can place your editor and terminal on the main screen, put research and chat on the second monitor, and apply your preferred volume. A Study mode can use a different arrangement and choose which managed apps to close when you leave Work.

  1. Create a mode for one task and add its apps, files, folders or URLs.
  2. Connect both monitors, arrange each app where you want it, and save the mode's window layout.
  3. Choose a global shortcut for the mode, then switch to another mode and back to test the placement.
  4. If an app opens slowly or changes its window on launch, adjust its launch options and recapture the layout.

See the suko mode walkthrough for the app and layout controls. Our window-layout guide compares Windows Snap, FancyZones and saved workspaces in more detail.

When an app still opens on the wrong display

  • Only one app misbehaves: close and reopen it on the same monitor setup. Check that app's own window or session settings. Moving other apps successfully points to an app-specific behavior.
  • Windows change screens after docking: confirm the display numbers and Extend mode, then try the monitor-location setting above. A changing dock or disconnected screen can alter the available desktop area.
  • A game ignores the saved layout: check its in-game display setting. Full-screen games often manage their display choice themselves; test them separately from ordinary desktop windows.
  • A saved workspace opens duplicate windows: try PowerToys' Move existing windows option or the app's own launch arguments. PowerToys documents that launch behavior varies by application.

If windows move after sleep or restart even when you have not launched a saved workspace, the window-position troubleshooting guide helps separate monitor reconnection from app startup behavior.

Common questions

Can Windows 11 force every app to open on monitor 2?

Windows can move an active window between monitors and remember open-window locations when a display reconnects. For a repeatable group of apps on specific screens, launch a saved workspace. Individual apps may still control how their windows first appear.

What shortcut moves an app to my second monitor?

Activate the window and press Win + Shift + Right Arrow or Left Arrow, depending on where the second monitor sits in Windows Display settings.

Will my multi-monitor layout return after a restart?

A saved PowerToys workspace or suko mode can reopen and position its apps after a restart. The Windows monitor-location setting is intended for windows that were open when a monitor disconnected and reconnected.
