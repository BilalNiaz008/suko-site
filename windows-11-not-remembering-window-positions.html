Windows 11 not remembering window positions? Here's what to check

A window that moves after you unplug a monitor needs a different fix from an app that opens in the wrong place after a restart. Find the cause first, then restore the layout you actually want.

Short answerIf windows move when you undock or reconnect a monitor, turn on Remember window locations based on monitor connection in Settings → System → Display → Multiple displays. If you need to reopen apps in chosen positions after a restart, capture a workspace with PowerToys Workspaces or suko. The Windows checkbox is for monitor reconnection, not a saved launcher for every app.

Updated September 30, 2026 · 5 minute read

When do the windows move?

Before changing settings, reproduce the problem once. Keep the affected apps open and unplug your external monitor, then reconnect it. Separately, close and reopen one app without touching the monitor. Those two tests tell you whether Windows is losing a display layout or the app is choosing a new starting position.

What happensStart here
Windows shift when a monitor disconnects, the PC sleeps or a laptop is undockedCheck the Multiple displays options and monitor connection.
One app opens at the wrong size or location, even on a single displayTest that app's own window behavior.
You restart Windows and want several apps reopened in a chosen layoutSave a launchable workspace.

This distinction matters: there is no one checkbox that turns a whole closed desktop session into a reusable set of applications and positions.

Fix positions after a monitor disconnects

  1. Open Settings → System → Display.
  2. Expand Multiple displays.
  3. Enable Remember window locations based on monitor connection. You can also enable Minimize windows when a monitor is disconnected if that matches how you work.
  4. Arrange your open windows, disconnect the external display, reconnect it, and check whether they return.

Microsoft documents these controls for Windows 11's docking and display-reconnection behavior in its multiple-monitor guide. The second checkbox controls what happens while a display is absent; it is optional.

If the option is already on, check that Windows still recognizes the same monitors. In Display settings, use Identify to match each screen number to its physical display and drag the display rectangles into the correct order. If a screen is missing, expand Multiple displays and choose Detect. Check the cable or dock connection and Windows updates too; Microsoft lists those as the first checks for external displays.

Changing between Extend, Duplicate and a single display also changes the space available for windows. Press Win + P to check the current display mode. Once the intended monitors are connected in Extend mode, arrange the windows again and repeat the disconnect test.

If only one app forgets its place

Leave the monitor setup unchanged. Move the problem app to a distinctive position, close it normally, and reopen it. If other apps stay put but this one resets, the monitor checkbox is unlikely to help. Applications can choose their own startup size and location, and some open a new window for each file or project.

Check that app's preferences for opening a previous window or session. Then test the app with its usual document or project, because a blank launch may behave differently. Avoid random registry edits or “fix all windows” scripts until you know the issue affects more than one app.

Restore a layout after restarting Windows

A restart closes your running applications. If your goal is “open my editor, browser and notes across two monitors exactly as I use them,” save that setup as a workspace that you can launch again. For the difference between Windows restartable apps, Startup and a chosen app group, see the reopen-apps guide.

Option 1: PowerToys Workspaces

Microsoft's free PowerToys Workspaces can capture the apps and positions on your desktop. Enable Workspaces in PowerToys, open its editor, choose Create workspace, arrange the apps, and select Capture. Name the workspace and save it with a desktop shortcut. After a restart, use that shortcut to launch the apps and move their windows into the recorded positions.

PowerToys may move an existing window or launch another instance depending on the app. Its Move existing windows option helps when you want to reuse windows that are already open. Test the saved workspace with your real apps; an app that starts slowly or opens a separate window may need adjustment.

Option 2: a suko mode

If you move between different setups during the day, create one suko mode for each task. A Work mode might open your editor, a project folder and your work browser profile, then arrange those windows across both monitors. A Gaming mode can select the work apps to close before opening the game and changing the volume.

  1. Create a mode named for the task, such as Work or Study.
  2. Add the applications, files, folders or URLs that belong in it. Set launch delays for apps that need extra time to open.
  3. Arrange the windows on the connected displays and save the mode's window layout.
  4. Choose the apps to close when switching away, and add a global shortcut if you want to return to the setup with one key combination.
  5. Restart the PC, launch the mode, and adjust any app that opens differently before saving the layout again.

The suko mode walkthrough shows the app selection, launch options, layout and shortcut controls. For a broader comparison of layout tools, see our guide to saving a Windows 11 window layout.

Common questions

Why do my windows move when I wake my laptop?

If the external monitor temporarily disconnects during sleep or docking, Windows may rearrange open windows for the displays it can see. Check the monitor connection and turn on Remember window locations based on monitor connection under Settings → System → Display → Multiple displays.

Does “Remember window locations” reopen my apps after a reboot?

No. Microsoft describes the setting for windows on a disconnected and reconnected monitor. To reopen a set of apps in saved positions after a reboot, launch a captured workspace.

Can I save different layouts for work and gaming?

Yes. Save each arrangement as its own PowerToys workspace or suko mode. suko modes can also include which apps to close and which system settings to apply when you switch.

Create a suko mode for the apps, monitor positions and settings you use together. Launch it whenever your desktop needs a reset.
