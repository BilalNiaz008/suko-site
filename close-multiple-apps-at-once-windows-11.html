How to close multiple apps at once in Windows 11

A crowded desktop can mean you need to hide windows for a moment, finish several apps, or move into a different task. Those actions behave differently, especially when a document has unsaved work.

Short answerTo close a few open windows, activate each one and press Alt + F4, responding to any save prompt. Win + M only minimizes windows. If you repeatedly switch from one known group of apps to another, a suko mode can close the selected apps from the previous mode and open the next group with one shortcut. Reserve force-ending for an app that has stopped responding.

Updated October 6, 2026 · 5 minute read

First, decide what “close all” means

The fastest action depends on what you want to happen next. If you need privacy for a minute, hide the windows. If a task is finished, close only its apps so the rest of the desktop stays intact. If an app is frozen, end its process. Treating all three as the same action can leave work unsaved or shut down something you still need.

Microsoft's Windows shortcut list defines Alt + F4 as closing the active window and Win + M as minimizing all windows. It does not describe a universal shortcut that safely closes every running application.

Close a handful of apps normally

  1. Save the files or drafts you are working on.
  2. Click the first app window and press Alt + F4.
  3. Respond to the application's save or confirmation dialog before moving on.
  4. Repeat for the other apps you want to leave. Keep unrelated tools open.

This is the smallest built-in solution for a few windows. A browser may close a window while continuing to run in the background, and an app with several documents may need more than one close action. Watch what actually exits instead of assuming the taskbar has become empty. Pressing Alt + F4 on the desktop when no app window is active can open the Windows shutdown dialog, so check which window has focus.

If you only need a clean-looking screen, use Win + D to show the desktop or Win + M to minimize windows. Neither quits an app or frees its work from memory. That distinction matters if you are about to launch another demanding set of programs.

Close a repeatable app group when switching tasks

The real time sink is often the transition from Work to Gaming, Study or a meeting. You close chat and project tools, open another group, arrange its windows and change the sound level. A suko mode stores the apps, URLs, layout and Windows settings for one context, with choices for which managed apps close when you leave it.

  1. Create a Work mode with the editor, browser profile, chat and project files you use together.
  2. Choose which Work apps should close when you change modes. Leave persistent tools, such as a password manager, outside that close list.
  3. Create the next mode, such as Gaming or Study, with its own apps, saved window positions and settings.
  4. Assign a hotkey and test the switch while the apps are open. Check any documents with unsaved changes before making the switch part of your routine.

This approach closes a selected task group, not every process on the PC. The suko mode walkthrough shows its app-selection and close-on-switch controls. Our guide to opening multiple apps covers the other half of the transition; the hotkey guide shows how to trigger the whole mode.

When an app will not close

If an application does not respond to its normal close button or Alt + F4, open Task Manager with Ctrl + Shift + Esc, select the stalled process and choose End task. This is for a stuck program, not the usual way to finish a group of apps: ending a process can discard work that the app has not saved.

Windows also provides the taskkill command, which can target one or more process IDs or image names. Microsoft documents /f as the option that forcefully ends a process. Avoid broad wildcard commands and confirm the process name before using them; a command that ends every matching process can also end work you meant to keep.

Common questions

Does Win + D close all apps?

No. It shows the desktop by hiding open windows. The applications remain running. Win + M minimizes all windows and also leaves the applications open.

Does Alt + F4 close every app at once?

No. It closes the active window. Repeat it for each app you want to finish, responding to any save prompt. When the desktop has focus, Alt + F4 can show the shutdown dialog.

Can suko close only my Work apps?

Yes. A mode can choose managed apps to close when you switch away from Work, while opening the apps and layout for the next mode. Test that selection before relying on it with unsaved documents.
