How to save and restore a window layout in Windows 11

Windows offers several ways to arrange windows. The right one depends on whether you need a temporary layout, custom zones, or an entire workspace that launches on demand.

Short answerUse Snap Layouts for quick arrangement, FancyZones for reusable zones, PowerToys Workspaces to launch apps into saved positions, or suko when you also want to close the previous workspace, apply Windows settings, and switch by hotkey or context.

Updated September 19, 2026 · 7 minute read

Four ways to manage a Windows 11 layout

A window layout is the position, size and monitor assigned to each app window. Windows 11 can help with arrangement, but “save” can mean different things: keeping windows in zones, reopening a set of apps, or restoring a complete task context.

1. Snap Layouts: quickest for the current session

Hover over a window’s maximize button or press Win + Z, choose a layout, then fill its remaining zones. This is built into Windows 11 and works well when you only need two or three windows arranged now.

Snap Layouts are not a full workspace launcher. They do not define which apps belong to Work or Study, close apps from the previous task, or apply settings such as volume and Do Not Disturb.

2. FancyZones: best for custom zones

FancyZones, part of Microsoft PowerToys, lets you design custom screen zones and move windows into them. It is useful for ultrawide displays and layouts that Windows Snap does not provide.

FancyZones controls placement. You still open the apps and decide which workspace is active.

3. PowerToys Workspaces: launch and position apps

PowerToys Workspaces can capture a group of applications and their positions, then relaunch that group later. It is a strong free option when your main goal is recreating one app arrangement.

4. suko: switch the complete context

suko treats the layout as one part of a mode. A Work mode can close the managed Gaming apps, open your editor and browser profile, restore both monitors, lower the volume and enable Do Not Disturb. You can start it with a global shortcut, schedule, Wi-Fi network, power state or app launch.

Save a multi-monitor layout with suko

  1. Create a mode. Name the context—such as Work, Study or Gaming—and add the apps, URLs, browser profiles or commands it needs.
  2. Arrange the windows. Open the apps and place each window at the size and monitor you want.
  3. Capture the layout. Save the current positions to the mode. suko records where each managed window belongs.
  4. Choose a trigger. Bind a global hotkey or choose an automatic trigger such as a schedule or Wi-Fi connection.
  5. Test the switch. Move the windows, change modes, then return. Recapture if your monitor arrangement changes.

What can break a saved layout?

Any layout tool needs a stable way to identify a window. An application update may change its window title or startup behavior. Disconnecting a monitor also changes the available desktop area. After a major display or application change, launch the mode, correct the affected window, and capture the layout again.

Applications that open documents in unpredictable windows can also need a moment before they are ready to move. Test your real setup before relying on it for a presentation or live session.

Questions

Can Windows 11 save a window layout?

Snap Layouts arrange open windows. PowerToys Workspaces goes further by saving a group of applications and relaunching them into recorded positions.

Can a saved layout work across multiple monitors?

Yes. PowerToys Workspaces and suko can record application positions across multiple monitors. If you change the monitor configuration, capture the layout again.
