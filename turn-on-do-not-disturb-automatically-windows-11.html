How to turn on Do Not Disturb automatically in Windows 11

Quiet time is useful when it starts with your work, not after the first distracting banner. Windows can silence notifications at set times or during certain activities. You can also make it part of a complete workspace switch.

Short answerOpen Settings → System → Notifications, expand Turn on do not disturb automatically, and choose a time or activity. Use Set priority notifications to allow important people and apps through. If quiet time should begin when you switch to a Work or Focus setup, add Do Not Disturb to that suko mode.

Updated October 3, 2026 · 5 minute read

Set an automatic Windows rule

  1. Open Start → Settings → System → Notifications.
  2. Expand Turn on do not disturb automatically.
  3. For a predictable routine, enable the time-of-day rule and set the hours. Review its repeat setting so it matches your week.
  4. Or enable an activity rule: while duplicating the display, playing a game, or using an app in full-screen mode.
  5. Test the condition. Open the notification center with Win + N to see whether Do Not Disturb is on and to review notifications later.

Microsoft lists these conditions, plus the first hour after a Windows feature update, in its Windows notifications and Do Not Disturb guide. The automatic options are based on time or those Windows activities; they do not offer a built-in rule for “when I open my work project.”

Allow the notifications that matter

Do Not Disturb sends most alerts to the notification center without showing banners. It does not delete them. Windows can still show alarms, reminders, and notifications you explicitly prioritize.

  1. In Settings → System → Notifications, open Set priority notifications.
  2. Choose whether calls and reminders should interrupt you.
  3. Under Apps, add only apps that must show notifications during quiet time.
  4. Send yourself a test notification from an allowed and a non-allowed app, then check the notification center.

Keep emergency or accessibility alerts available if you rely on them. For a single noisy application, its own notification settings may be a better fix than silencing the entire desktop.

Do Not Disturb or a Focus session?

Do Not Disturb is the notification setting. A Windows Focus session adds a timer and temporarily hides taskbar badges and flashing; it also turns on Do Not Disturb. Start Focus from the notification area when you want a timed block. Use an automatic Do Not Disturb rule for regular hours or full-screen activities.

If Do Not Disturb was already on before a Focus session, Microsoft says it remains on when the session ends. Check the bell icon when you expect notifications to resume.

Make quiet time part of a work mode

Windows' built-in rules are enough when a clock or full-screen app defines your quiet time. A task change is different: the apps, windows and notification preference should change together.

  1. Create a Work or Focus mode in suko and add the apps, URLs and files for that task.
  2. Arrange and save the windows if you want the same layout next time.
  3. Set that mode's Do Not Disturb preference, along with volume or brightness if useful.
  4. Activate the mode with a workspace hotkey and confirm the apps and notification state change as expected.
  5. Create another mode for your next task and test its notification preference before relying on the switch.

A time-based workday can use a scheduled workspace. Keep the manual shortcut too, since meetings and focused work do not always start on the clock.

If notifications still interrupt you

  • Check priority: an app on the priority list can still display a banner. Remove it if it does not need to interrupt you.
  • Check the type of alert: an in-app pop-up or an app's own sound may not be a Windows notification. Review that app's settings separately.
  • Check the trigger: a full-screen rule is not the same as maximizing a window. Test the actual activity you configured.
  • Check Focus: ending a Focus session does not necessarily turn off Do Not Disturb if it was already on.

Common questions

Can Windows 11 turn on Do Not Disturb at a specific time?

Yes. In Settings → System → Notifications, expand Turn on do not disturb automatically and set the time-of-day rule.

Will I lose notifications while Do Not Disturb is on?

No. Most notifications go to the notification center so you can review them later. Alarms, reminders and priority apps may still appear.

Can Do Not Disturb turn on when I switch to work?

A suko mode can apply a Do Not Disturb preference while it opens your work apps and restores their layout. Test the mode and the next mode's notification state on your PC.
