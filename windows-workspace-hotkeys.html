Windows workspace hotkeys: switch a complete setup in one step

Windows has shortcuts for moving between virtual desktops. A workspace hotkey can go further and rebuild the apps, layout and settings required for the next task.

Short answerPress Win + Ctrl + ← or → to switch Windows virtual desktops. To switch an entire workspace, bind a global hotkey in suko to a mode containing the apps, URLs, layout and system settings you want.

Updated September 19, 2026 · 6 minute read

Built-in Windows virtual desktop shortcuts

These Windows 10 and 11 shortcuts manage multiple desktops:

ShortcutAction
Win + TabOpen Task View and see desktops
Win + Ctrl + DCreate a new virtual desktop
Win + Ctrl + ←/→Move between virtual desktops
Win + Ctrl + F4Close the current virtual desktop

These keys change which desktop you see. They do not launch a task-specific app group or reset the window layout. If Work is not already prepared, you still have to prepare it.

What a complete workspace hotkey can do

A complete switch describes the desired result instead of only moving to another surface. For example, a Focus shortcut might:

  • Close managed chat and gaming applications from the previous mode.
  • Open an editor, project folder, reference site and focus-music app.
  • Restore each window to its position across two monitors.
  • Set a lower volume and turn on Do Not Disturb.

A script can launch several programs, but a workspace tool is easier to maintain when the switch also needs layout management and state from the previous context.

Bind a suko mode to a global hotkey

  1. Create the mode. Group everything needed for one context, such as Work, Focus, Study or Gaming.
  2. Add launch targets. Choose desktop applications, browser profiles, URLs and terminal commands.
  3. Save the layout. Arrange the open windows and capture their monitor, position and size.
  4. Set Windows preferences. Add the volume, brightness and Do Not Disturb state for the mode.
  5. Record a unique key chord. Use a combination that does not conflict with Windows or an application.
  6. Test from another mode. Confirm that unwanted apps close and the next setup finishes in the expected state.

Choose a shortcut that does not collide

A good global shortcut is memorable, distinct, and unlikely to be claimed by the active application. Start with three keys, such as Ctrl + Shift + a letter related to the mode. Avoid common editing keys and Windows-reserved combinations.

Keep the set consistent: Work, Focus, Gaming and Study might share the same modifier keys and use only a different final letter. Consistency matters more than cleverness because the shortcut needs to become automatic.

When a hotkey should become automatic

A shortcut is best when you choose the moment. Some contexts have an obvious external signal instead:

  • Start Work on weekday mornings with a schedule.
  • Start a travel mode when a particular Wi-Fi network connects.
  • Change the setup when the computer moves between battery and external power.
  • Restore supporting tools when a chosen application launches.

Use one clear trigger per mode at first. Add automation only after the manual switch behaves reliably.

Questions

What is the shortcut to switch desktops in Windows 11?

Press Windows key + Ctrl + Left Arrow or Right Arrow. Press Windows key + Tab to open Task View and select a desktop visually.

Can one Windows hotkey open several apps?

Yes. A hotkey can call a script or workspace tool. A suko hotkey can open apps and URLs, restore a layout and apply Windows settings in the same mode switch.

Give every context one shortcut

Build the mode once. Use its hotkey whenever you need the same apps, layout and Windows settings again.
