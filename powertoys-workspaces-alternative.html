PowerToys Workspaces alternative for Windows 11: when to use suko

PowerToys Workspaces is a capable way to reopen apps in saved positions. If your repeated task also involves closing the last set of apps or changing Windows settings, compare the full switch before choosing a tool.

Short answerStart with PowerToys Workspaces when you mainly need to capture, launch and reposition an app group. Use suko when changing from Work to Study or Gaming should also close selected apps from the previous mode, open the next set and apply volume, brightness or Do Not Disturb. Keep PowerToys if it already covers your routine.

Updated October 5, 2026 · 6 minute read

What PowerToys Workspaces does well

Microsoft's Workspaces documentation describes a desktop manager that captures open applications and their window positions. You arrange a desktop, select Create workspace and Capture, edit the saved setup, then launch it from the Workspaces editor or a desktop shortcut. You can pin that shortcut to the taskbar. This is a strong free solution when the repeated job is “open these apps in these places.”

PowerToys also supports app-specific command-line arguments. That can open an editor with a particular file or project, or a browser with chosen URLs. Its Move existing windows option can reposition an app that is already open while launching the missing apps. If you have one steady desk setup each morning, try this before adding more workflow rules.

Microsoft notes two details worth testing with your own apps. Some applications reuse a running window while others open another instance; for example, VS Code can use --reuse-window when you want to move the existing window. Workspaces also launches an app before moving it, so you may briefly see the window jump into place. Those behaviors are normal and documented.

When the repeated work is switching, not just launching

Consider a laptop used for three activities. In Work, an editor, project folder, browser profile and chat belong across two monitors. In Study, the editor and chat should give way to notes and references. In Gaming, the work apps should close and the sound should change. Relaunching a saved app group handles only part of that transition.

suko calls each setup a mode. A mode records its apps, URLs, browser profiles, launch commands, window layout, and settings such as volume, brightness and Do Not Disturb. Switching modes can close the managed apps you selected from the previous context before opening the next group. A global hotkey gives each mode a direct way in, and a schedule can start a mode at a chosen time.

The practical distinction is the state you manage: PowerToys Workspaces is especially good at restoring an app arrangement. suko is useful when you also want a repeatable transition from one task to another. Microsoft documents PowerToys' launch and positioning behavior; the suko mode walkthrough shows the app, close-on-switch, layout and shortcut controls.

A fair 10-minute test

  1. List the steps you repeat between two tasks: what opens, what closes, where windows go, and which settings change.
  2. Capture one PowerToys workspace. Launch it from a clean desktop and again with some apps already open. Check for extra windows and position changes.
  3. Create one suko mode with the same apps and layout. Add close-on-switch choices and system settings only if they matter to your workflow.
  4. Switch away and back. Confirm the expected apps close and reopen, the windows return to the right monitors, and any system setting changes are useful.
  5. Keep the smaller routine that reliably gets you ready. Avoid setting both tools to launch the same app group, which can create duplicates.

Saved layouts can need a refresh when an app changes its startup window or you change monitors. Test your actual programs, especially browsers, single-instance apps and anything that runs as administrator. Microsoft's Workspaces documentation calls out a current issue with repositioning apps launched as administrator; treat that as an app-specific check before you depend on a layout.

Common questions

Is PowerToys Workspaces enough for a daily Windows setup?

Often, yes. If the job is launching and positioning the same apps, PowerToys Workspaces is a good free starting point. Add a mode-based tool when you also need to close the previous task's apps or apply settings during a switch.

Can PowerToys Workspaces move apps that are already open?

Yes. Microsoft's Workspaces documentation describes a Move existing windows option. App behavior still varies, so test each program; some may start another instance unless you adjust its launch arguments.

Will suko replace FancyZones or Windows virtual desktops?

suko manages task modes with apps, layouts and settings. FancyZones focuses on custom window zones, while virtual desktops separate open windows. Use whichever of those controls solves a real part of your workflow.
