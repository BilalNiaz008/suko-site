How to set up Focus mode in Windows 11 for deep work

A focus timer can quiet notifications, but a productive session also needs the right apps and windows ready. Set up Windows Focus first, then make the rest of your desktop repeatable.

Short answerOpen Settings → System → Focus, choose a session length, and start a focus session. Windows turns on Do Not Disturb and quiets taskbar badges and flashing by default. To open your editor, notes and reference pages in a saved layout, create a suko Focus mode and launch it before starting the Windows timer.

Focus, Do Not Disturb and a focus workspace

Windows 11 has two related controls. Focus is a timed session in the Clock app. By default it turns on Do Not Disturb and hides taskbar notification badges and flashing while the timer runs. Do Not Disturb can also be turned on by itself or automatically during chosen times and activities. Microsoft explains these behaviors in its Focus guide and notification guide.

A focus workspace is the set of apps, pages and window positions you use for the task. For example, writing might need a document, research browser window and notes on two monitors. Windows Focus quiets interruptions; a suko mode can prepare that app setup and apply its own Windows settings. Use the two together when you want both a timer and a repeatable desktop.

Start a Windows 11 focus session

  1. Open Settings → System → Focus. Set your preferred session duration and choose whether to show the timer, hide taskbar badges, stop flashing and turn on Do Not Disturb.
  2. Select Start focus session. Windows starts the timer and applies the selected focus behaviors.
  3. For a quicker start next time, press Win + N, choose a duration in the notification area, and select Focus. You can also start a session from the Clock app.

Microsoft notes that Focus uses the Clock app. If Clock has been removed from your PC, reinstall it before troubleshooting the timer. You can end a session early, and Windows sends a notification when it finishes. Starting a session does not close distracting applications or arrange your windows.

Keep important alerts while Do Not Disturb is on

Do Not Disturb silences most notification banners, but alarms, reminders and apps you allow may still appear. Open Settings → System → Notifications and review Set priority notifications if you need calls, reminders or a particular app to break through. This is useful for a work session where you want quiet without missing one essential contact.

If you prefer quiet hours without a timer, expand Turn on Do Not Disturb automatically on the same Notifications page. Windows offers conditions such as certain times of day, gaming, full-screen apps and duplicating a display. A scheduled Do Not Disturb period still leaves your apps and layout as they were; it controls notifications.

If Focus ends and notifications remain quiet, check whether Do Not Disturb was already on before the session. Microsoft's Focus documentation says it stays on afterward in that case.

Create a repeatable Focus workspace with suko

A suko mode groups the apps and settings for one activity. A Focus mode might open your editor, a project folder, a reference site and notes; place each window on the monitor you use for it; lower system volume; and apply Do Not Disturb. When you switch from another suko mode, choose which of its managed apps should close so the old task does not remain in the way.

  1. Create a mode named Focus or for the specific task, such as Writing or Coding.
  2. Add the desktop apps, files, URLs and browser profile needed for that work. Keep the list short enough to avoid launching distractions.
  3. Arrange the windows and save their layout. If you use two displays, test the positions with both connected.
  4. Set your preferred volume and Do Not Disturb state, then bind a memorable global shortcut to the mode.
  5. Switch to another mode and back to test the full transition. Then start a Windows Focus session if you also want its timer.

A simple 45-minute deep-work setup

Suppose you are editing a report. Launch a suko Writing mode that opens the document, research page and notes in their saved positions. Keep chat out of that mode, set a low volume and enable Do Not Disturb. Then start a 45-minute Windows Focus session from the notification area. When the timer ends, review the missed notifications in Notification Center and decide whether to continue or switch modes.

This sequence gives you a clear start and finish without requiring automation. If the work always begins at the same time, the scheduled app guide covers time-based launching; test the manual routine first so you know the app set is right.

Common questions

Does Windows Focus close distracting apps?

No. Focus starts a timer and reduces notifications and taskbar distractions. If you want a different set of apps open, prepare it separately, for example with a suko mode.

Is Do Not Disturb the same as a focus session?

No. Do Not Disturb controls notification banners. A focus session adds a timed period and can turn on Do Not Disturb as one of its settings.

Does a suko Focus mode start the Windows Clock timer?

The workflow in this guide uses suko for apps, layout and system settings. Start the Windows Focus timer from Settings, Notification Center or the Clock app when you want a timed session.
